¿De qué trata esta web?

Este sitio recoge información sobre los Sistemas de Gestión Empresarial (SGE): qué son, para qué sirven y cómo se usan en la práctica. El objetivo es entender cómo este tipo de software centraliza y facilita la gestión de los distintos procesos de una organización desde un único entorno.

Como ejemplo práctico de SGE se ha utilizado Odoo Community 19, una plataforma de código abierto que cubre áreas como ventas, contabilidad, inventario, recursos humanos o CRM, entre otras. A lo largo de las páginas se explica tanto la teoría general de los SGE como el funcionamiento concreto de Odoo.

Contenido de cada sección

SGE

Explica qué es un Sistema de Gestión Empresarial, los distintos tipos que existen (ERP, CRM, SCM, HRM, BI) y cuáles son sus características principales. Es el punto de partida para entender por qué este tipo de herramientas se han convertido en un estándar en la gestión de empresas.

Odoo

Cubre todo lo relacionado con Odoo: el proceso de instalación en Windows, la configuración inicial de la plataforma (empresa, módulos y usuarios), y el sistema de acceso seguro basado en roles, grupos y permisos. Todo en una sola página para tener una visión completa de cómo se pone en marcha este SGE.

Informes

Describe cómo generar informes en PDF, usar las vistas Pivot y Gráfico para analizar datos, y exportar información a formatos como CSV o Excel. También se mencionan otras formas de acceder a los datos, como la API o la consulta directa a la base de datos.
